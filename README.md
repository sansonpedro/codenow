# CodeNow

> Aprenda a pensar, não a decorar.

## O problema

A popularização da IA criou devs que sabem copiar respostas mas não entendem o porquê das coisas. Faltam lugares para estudar código de verdade — com profundidade, contexto e explicação.

O CodeNow resolve isso com um tutor que **não te dá a resposta**. Ele te faz as perguntas certas até você chegar lá sozinho.

## Para quem é

Para quem quer aprender e entender a lógica por trás do código. Se você só decora sem entender, na próxima vez você está no mesmo lugar.

## Stack

- [Next.js 15](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Shadcn/ui](https://ui.shadcn.com/)
- [Phosphor Icons](https://phosphoricons.com/)
- [Claude API](https://www.anthropic.com/) — Anthropic

## Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/sansonpedro/codenow

# Instale as dependências
pnpm i

# Rode o projeto
pnpm dev
```

Acesse `http://localhost:3000` no navegador.
